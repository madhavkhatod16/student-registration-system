# Student Registration System

A simple student management project built using HTML, CSS, and JavaScript.

## Features
- Student registration form
- Name, email, phone number, and course selection
- Saves student details using Local Storage
- Admin dashboard to view registered students
- Mark students as Contacted or Not Contacted
- Data persists in the browser using Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Files
- `index.html` — Student registration form
- `admin.html` — Admin dashboard and student list

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Register a student.
4. Open `admin.html` in the same browser to view registered students.

**Note:** Student data is stored in browser Local Storage, not in a database. Both pages must use the same browser storage origin to share data.
